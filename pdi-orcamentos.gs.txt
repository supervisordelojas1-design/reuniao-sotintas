/* ============================================================================
   NÚMERO DO ORÇAMENTO NOS PDIs — o que falta mandar do servidor
   Assistente ST · Só Tintas · outubro/2026 (app sw ast-v134)

   O app já sabe mostrar o número em todos os lugares: PDI Semanal do vendedor,
   PDI Mensal do vendedor, PDI Mensal de gerentes e supervisores (tela, termo em
   PDF e WhatsApp) e Painel de Metas (lista, WhatsApp e PDF). O que falta é o
   servidor mandar o número junto com cada orçamento.

   Regra em todos os pontos: enquanto o campo não vier, as telas ficam
   EXATAMENTE como estão hoje — sem coluna vazia, sem travessão e sem erro.
   A coluna do número só nasce quando a base manda.

   ──────────────────────────────────────────────────────────────────────────
   0) LENDO A COLUNA DO NÚMERO (modelo; ajuste ao nome da sua coluna)

   A base de orçamentos em aberto já tem a coluna do documento. Esta função
   acha a coluna por qualquer um dos nomes mais comuns do relatório, sem
   depender de acento nem de maiúscula:

   function orcDoc_(linha, cab) {
     var alvos = ['DOCUMENTO', 'DOC', 'NUMERO', 'N DOCUMENTO', 'NO DOCUMENTO',
                  'NUM DOCUMENTO', 'NUMERO DO DOCUMENTO', 'ORCAMENTO',
                  'NUMERO DO ORCAMENTO', 'N ORCAMENTO', 'NO ORCAMENTO',
                  'PEDIDO', 'PROPOSTA'];
     var norm = function (s) {
       return String(s || '').normalize('NFD').replace(/[̀-ͯ]/g, '')
              .replace(/[ºª°.ºN]/g, ' ').replace(/[^A-Za-z0-9 ]/g, ' ')
              .replace(/\s+/g, ' ').trim().toUpperCase();
     };
     var cabN = (cab || []).map(norm);
     for (var i = 0; i < alvos.length; i++) {
       var j = cabN.indexOf(alvos[i]);
       if (j >= 0) return String(linha[j] == null ? '' : linha[j]).trim();
     }
     return '';
   }

   Confira uma vez com Logger.log(cab) e, se a sua coluna tiver outro nome,
   basta acrescentar esse nome na lista 'alvos'.

   ──────────────────────────────────────────────────────────────────────────
   1) SERVIDOR BANCO — pacote do PAINEL DE METAS

   Hoje cada orçamento vai como uma linha de 6 campos:

     [vend, comMeta, data, cliente, telefone, valor]

     [vend, comMeta, data, cliente, telefone, valor, orcDoc_(linha, cab)]

   O Painel lê como r[6]. Com isso o número aparece na lista para ligação, no
   WhatsApp da lista, no PDF da reunião e no alerta do orçamento maior.
